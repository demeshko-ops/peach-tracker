# Автозбереження історії в Google Таблицю

Трекер — статична сторінка без сервера, тому писати в таблицю він може лише через
маленький скрипт-приймач усередині самої таблиці. Підключення разове, ~5 хвилин.

## Крок 1. Відкрити редактор скриптів

Відкрий свою таблицю → меню **Розширення → Apps Script**.

## Крок 2. Вставити код

У редакторі виділи весь наявний текст (`function myFunction() {}`) і заміни його
вмістом файлу [`Code.gs`](./Code.gs) з цього репозиторію. Натисни 💾 (Зберегти).

## Крок 3. Розгорнути як веб-додаток

**Розгорнути (Deploy) → Новий розгортання (New deployment)**:

| Поле | Значення |
|---|---|
| Тип (шестерня → Select type) | **Веб-додаток (Web app)** |
| Виконувати від імені (Execute as) | **Я (Me)** |
| Хто має доступ (Who has access) | **Будь-хто (Anyone)** |

Натисни **Розгорнути**. Google попросить дозволи — це нормально: скрипт пише лише
у твою таблицю. На екрані «Google не перевірив цей додаток» натисни
**Додатково (Advanced) → Перейти до … (Go to …)** і дай доступ.

> «Будь-хто» означає, що дані приймаються за секретним посиланням, яке знаєш лише ти.
> Не публікуй це посилання.

## Крок 4. Скопіювати посилання

Після розгортання скопіюй **URL веб-додатка** — він має вигляд
`https://script.google.com/macros/s/AKfycb.../exec`

## Крок 5. Вставити посилання в трекер

У трекері внизу відкрий **Твої дані → ☁️ Google Таблиця — автозбереження історії**,
встав посилання в поле і натисни **Синхронізувати зараз**. Має з'явитися
«Дані в таблиці ✓».

Готово. Далі кожне збережене тренування і кожен запис замірів вивантажуються
автоматично.

---

## Що з'явиться в таблиці

| Вкладка | Для чого |
|---|---|
| **Журнал** | Усі підходи одним плоским списком — зручно для зведених таблиць і графіків |
| **Прогрес вправ** | Вправи в рядках, тижні в стовпцях, у клітинці — максимальна вага тижня |
| **Заміри** | Вага, талія, живіт, попа, нога по тижнях |
| **Тиждень 1 … 12** | Окрема вкладка на тиждень: тренування, пробіжки й заміри цього тижня |
| **BACKUP** | Прихована вкладка з повною копією даних — з неї працює відновлення |

## Відновлення даних на сайті

Кнопка **«Відновити з таблиці»** зчитує вкладку BACKUP і повертає всі тренування,
пробіжки та заміри — наприклад, на новому телефоні або після очищення браузера.
Вкладку BACKUP не редагуй вручну: саме з неї відновлюються дані.

## Оновлення скрипта

Якщо колись зміниш `Code.gs`, зроби **Розгорнути → Керувати розгортаннями →
✏️ → Версія: Нова** — посилання залишиться тим самим.
